# CleanYourTV.org

[CleanYourTV.org](https://cleanyourtv.org/) provides an Android TV and Google TV launcher edition, illustrated setup guides, and an optional self-service installation kit maintained by Tyler.

The aim is a simpler TV home screen with quick access to the apps you use. Start by checking your device, then follow the backup, installation and restore instructions for your setup.

**[Visit the website](https://cleanyourtv.org/) · [Read the installation guide](https://cleanyourtv.org/guides/install) · [Check compatibility](https://cleanyourtv.org/compatibility)**

## Start here

| What you want to do | Resource |
| --- | --- |
| Understand the device and computer requirements | [Compatibility and requirements](https://cleanyourtv.org/compatibility) |
| Prepare your TV, back up settings and install the launcher | [Illustrated Android TV installation guide](https://cleanyourtv.org/guides/install) |
| Make the launcher open when you press Home | [Change the default Android TV launcher](https://cleanyourtv.org/guides/default-launcher) |
| Return to the previous TV home screen | [Restore guide](https://cleanyourtv.org/guides/restore) |
| See the optional installation kit | [Kit contents and pricing](https://cleanyourtv.org/pricing) |

Before changing a TV, confirm its operating system and keep a record of its original settings. A television's brand alone does not establish compatibility, and behavior can vary by firmware.

## What is available

- A launcher edition with the application ID `org.cleanyourtv.launcher`.
- Guides covering preparation, installation, default-home setup and recovery.
- A self-service kit with desktop installation tools and illustrated documentation.
- A website account for purchase records and downloads, with Google or email sign-in.

The kit is a one-time purchase. Review the current contents and requirements on the website before ordering.

## Project information

This repository is the public information hub for the **cleanyourtv.org edition**. It contains project information and links to the maintained guides.

The launcher edition builds on [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv), which is distributed under the MIT license. The upstream project and its `cleanyour.tv` website are separate from Tyler's `cleanyourtv.org` edition. Upstream device reports are not independent hardware certification of this edition.

For installation or order help, use the [support page](https://cleanyourtv.org/support). Do not post passwords, order details or payment information in public GitHub issues.
